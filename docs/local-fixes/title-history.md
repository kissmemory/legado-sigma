# 曾用名与文案自动校准（2026-11-19）

用户选择：只显示书籍详情，不显示在发现/搜索列表。

表现：详情简介顶部为“曾用名：历史书名1／历史书名2”，空一行后展示当前官网文案；如有手写简介，继续展示手写内容，不覆盖。按首次记录顺序去重，排除本次官网当前书名；改回旧名也正确排除当前名，仍保留完整已观察历史。

数据：使用现有Book.variable保存按固定晋江作品ID绑定的历史，不新增数据库表/列，跟随现有书架备份恢复。首次从书架已有旧名开始记录，不能恢复过去从未观察或保存的改名。详情来自发现的新Book实例时，按作品ID合并书架保存的历史。

更新：书籍详情信息获取成功时记录观察到的书名；晋江目录刷新且非刚从详情刷新进入时，额外刷新一份书籍信息副本，只合并源简介及历史，保留书架名、分组、进度和手写简介。信息查询失败时保留旧文案和历史，不中断原章节刷新；取消信号继续传播。增加每本晋江书一次详情请求。

显示：仅在BookInfoActivity.showBookIntro渲染时添加前缀，原始intro和customIntro不写入前缀，编辑页、导出与发现列表不受装饰影响；兼容HTML/Markdown标记。

验证：Java实现的6项新测试覆盖多次改名、去重、改回旧名、文案替换、无变化、空响应、格式与不变性，连同原绿点8项测试共14项通过。Android/Kotlin完整编译、14项Android项目测试、APK打包及签名检查已完成；手机实际安装与界面实测尚未执行。
